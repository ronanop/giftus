# Giftus Design System

## World
Intimate Indian celebration pages. The registry feels like a personal invitation wall — family photos lead, gifts live inside the story. Not a SaaS wishlist. Not Gifaa.

## Palette
| Token | Hex | Role |
|-------|-----|------|
| paper | `#FBF7F2` | Page ground |
| ink | `#1C1410` | Primary text |
| dusk | `#2A1F1C` | Deep celebration panels |
| rose | `#B84A5E` | Brand / CTA / love accent |
| rose-deep | `#8F3345` | CTA pressed |
| petal | `#F8E8EC` | Soft wash |
| blush | `#EDD0D6` | Warm section tint |
| sage | `#4A5D4E` | Secondary calm |
| sage-soft | `#E7EEE8` | Calm band |
| gold | `#A8894A` | Celebration highlight |
| marigold | `#C9963A` | Brighter festivity accent |
| mist | `#EFE8E1` | Borders / subtle fills |

Avoid: purple gradients, terracotta `#D97757`, Inter/Roboto, generic card grids in the hero.

## Type
- Display: **Fraunces** — soft optical serif for brand & registry titles
- Body / UI: **Figtree** — clear, friendly, mobile-readable

## Motion
- Landing: orchestrated hero reveal + ken-burns cover, scroll reveals (up / left / scale)
- Atmosphere: rose/marigold orbs, petal drift, heart floats
- Registry: gift-card lift + image zoom; fund bars grow once; claim pulse
- CTAs: soft shimmer on hover (`btn-glow`)
- Respect `prefers-reduced-motion` (all motion collapses)

## Layout principles
- Brand first in the hero
- Full-bleed emotional photography on registry covers
- Cards only for interactive gift / fund units
- Mobile-first; iOS UPI flows get QR + app buttons + copy
- Color bands (petal / sage / dusk) create scroll rhythm without card spam

## Baby shower whimsy (occasion = baby_shower)
- Storybook / invitation wall: parchment ground, forest **grove** (`#3F523F`), arched category cards with sage bows
- Script accent: **Great Vibes** for “A Little One Is Almost Home”
- Category explorer: illustrated arch tiles → filter gifts below
- Keep Giftus rose CTAs on non-baby occasions; grove CTAs on baby shower pages
